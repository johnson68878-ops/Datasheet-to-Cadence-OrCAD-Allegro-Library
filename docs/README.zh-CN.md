# 项目说明

本项目尝试由程序自己的通用引擎读取PDF规格书，提取脚位、封装尺寸与来源证据，生成OrCAD原理图库和Allegro PCB封装，再进行原生回读与工程审核。AI用于协助开发，不应代替程序逐份填写答案。

目前属于工程预览，尚未达到全面自动建库。原理图库在私有试用中相对成熟，主要困难在不同版式的尺寸、表头、变体、脚位完整性与焊盘角色识别。42份穿戴式常用器件规格书用于开发/回归验证，不代表重新训练了底层OCR模型；原PDF不公开。

历史独立PDF原生通过9份/12候选，另有官方附件辅助1份及警告1份。最新完整解析基线42份/54候选，13候选具草稿资格。上述私有结果不是这个去识别化公开副本的可复现成功率，也不代表17.2兼容或正式入库批准。

公开副本包含通用Python源码、桌面/UI源码、部分通用工具、合成测试及英文架构/历程/问题清单。板级参考规则现已去识别化公开；客户文件、原始Markdown报告和证据数据不公开，公开版可能与内部EXE行为不同。请先阅读README及PUBLICATION_SCOPE。

欢迎贡献：统一OCR坐标、跨页/合并表头、多变体隔离、尺寸线/圆形焊盘绑定、原生CAD验证以及更完善的可公开合成测试。禁止按厂家、料号、文件名或哈希写答案特例；重要信息缺失时不能猜值。最终仍需硬件和Layout工程师审核。
