# Public snapshot scope

Included: the generic Python package, desktop source with neutral branding, UI source, selected generic audit utilities, synthetic tests, an empty company-rule example, public architecture/history/problem documentation and MIT license.

Excluded: the original Git history; source datasheets; customer/board/schematic files; extracted OCR/table snapshots; reviewed answer fixtures; native reference catalogs and libraries; internal logs and correspondence; personnel information; corporate logos; binaries; credentials; downloaded third-party dependencies/model weights; internal corpus-specific scripts and private-data test functions.

The reference_defaults module now includes owner-authorized anonymized board-derived fallbacks; see BOARD_REFERENCE_RULES.md. Do not treat public outputs as byte-identical to internal outputs. Original internal Markdown reports were replaced with curated technical documentation rather than blindly copied. All generic package modules are represented, but this is intentionally not every local file.

The public suite is synthetic and does not reproduce the 42-document acceptance corpus. Private outcome statistics are historical context only. Native CAD testing remains the contributor's responsibility on licensed installations.

Local-only export preparation tools, private mappings and test logs are not committed. No original repository objects are reused. GitHub account attribution is retained only as the public project owner's identity.
